# Model card (`arabidopsis-gehring-v1`)

- **Species:** Arabidopsis thaliana (TAIR10/Araport11 locus identifiers)
- **Accessions:** Col-0, Ler, Cvi; C24 for ROS1 homeostasis
- **Window:** gametophytes through 7 DAP seed
- **Resolution:** allele copies, context-specific methylation site counts, coarse histones, sRNA pools
- **Not in v1:** 3D chromatin, new TE insertions, selection, non-Arabidopsis profiles, adaptive stress memory
- **Intended use:** mechanistic hypothesis testing and architecture experiments via one-way ports
- **Out of scope:** clinical, agricultural release, or genome-wide quantitative GEO refits
