# ADR 0001: Gehring-aligned research contract

## Status
Accepted

## Decision
V1 is a biology-first Arabidopsis seed epigenetics simulator. Kubernetes orchestrates runs; it is not a metaphor for methylation. The v0 CPU-analogy controller is frozen.

## Consequences
All scientific claims must cite [docs/biology/CLAIMS.md](../biology/CLAIMS.md). Application integrations use one-way ports only.
